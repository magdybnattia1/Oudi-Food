# OUDI FOOD

نظام كاشير عربي RTL للمطاعم السريعة، يعمل محليًا على جهاز Windows واحد باستخدام Electron وSQLite.

## التشغيل أثناء التطوير
- ثبّت Node.js إصدار LTS على Windows 64-bit.
- افتح مجلد المشروع في Terminal ثم نفّذ:
  ```bash
  npm install
  npm start
  ```

## إنشاء EXE لويندوز 64-bit
على Windows 64-bit بعد تثبيت التبعيات:
```bash
npm run build:win
``
ينتج ملف تثبيت داخل مجلد `dist`. يتطلب إنشاء الحزمة تثبيتًا أوليًا للتبعيات والإنترنت؛ التطبيق بعد بنائه يحفظ البيانات محليًا في مجلد بيانات المستخدم ولا يحتاج اتصالًا بالإنترنت للتشغيل. يعتمد الخط على خطوط الجهاز عند عدم توفر خط عربي مخصص.

## البيانات والنسخ الاحتياطي
قاعدة SQLite موجودة في مجلد بيانات التطبيق الخاص بالمستخدم. استخدم صفحة النسخ الاحتياطي لتصدير نسخة JSON. لا تحذف قاعدة البيانات أثناء تشغيل التطبيق.

## ما يتضمنه الإصدار الحالي
- واجهة الكاشير لطلبات الدليفري والتيك أواي؛ اسم العميل وهاتفه وعنوانه مطلوبة للدليفري فقط.
- اختيار العدد والحجم والسعر عند الضغط على الصنف، مع اختيار حار أو عادي، وفاتورة تطبع بزر مستقل.
- إضافة الأصناف وتحديد أحجام متعددة لكل صنف بسعر مستقل، ثم اختيار الحجم والإضافات من نافذة واضحة عند إضافته للطلب.
- إدارة العملاء والمندوبين والخامات، وتسجيل المصروفات وحركة الخزنة.
- وصفات تربط الأصناف بالخامات والتكلفة والمخزون.
- ملخص المبيعات اليومي وتقارير الأيام السابقة.
- حفظ محلي دون تسجيل دخول أو مزامنة سحابية.

الأسعار الافتراضية والخامات تجريبية ويجب استبدالها ببيانات المطعم. يمكن استعادة ملف النسخة المصدّر من صفحة النسخ الاحتياطي؛ الاستعادة تستبدل البيانات الموجودة حاليًا.

هذا مستودع مستقل عن Oudi System Cash.
