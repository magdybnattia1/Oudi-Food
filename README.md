# OUDI FOOD

نظام كاشير وإدارة طلبات دليفري للمطاعم، يعمل محليًا بدون إنترنت على Windows 64-bit.

## المميزات المستهدفة
- واجهة عربية بالكامل واتجاه RTL.
- استقبال طلبات الدليفري وإدارة العملاء والعناوين.
- المنتجات والأحجام والإضافات.
- حالات الطلب من الجديد حتى تم التوصيل.
- شاشة المطبخ وإدارة المندوبين.
- المخزون والخامات والمصروفات والخزنة والتقارير.
- قاعدة بيانات SQLite محلية ونسخ احتياطي.

## التشغيل أثناء التطوير
يتطلب Node.js LTS على Windows:
```bash
npm install
npm start
```

## إنشاء نسخة Windows
```bash
npm run build:win
```

المشروع مستقل تمامًا عن Oudi System Cash.
